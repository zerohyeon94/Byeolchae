# ADR-015 직원 프로필 사진

2026-11-18 Zero 결정.

## 배경

Discord에서 직원(ADR-012 15팀 41명)의 글은 모두 봇 하나가 채널 웹훅으로 올린다. 게시 이름만 `[이름 · 직책]`으로 바꾸고 사진은 정하지 않아서, 41명이 같은 웹훅 기본 사진으로 보였다. 이름을 읽기 전에는 누가 말했는지 알아보기 어려웠다.

직원마다 사진을 붙이는 방법은 두 가지였다.

1. 직원마다 Discord 봇 계정을 따로 만든다. 멤버 목록에 직원이 각자 보이지만, 토큰 41개와 Gateway 연결 41개를 관리해야 하고 게시 경로(`ChatIO`)를 바꿔야 한다.
2. 지금처럼 봇 하나와 웹훅으로 올리고, 게시할 때 `avatar_url`을 함께 넘긴다.

## 결정

1. **웹훅 사진**: 2번으로 한다. 봇 계정은 별채 하나로 둔다.
2. **설정 위치**: 사진 주소는 회사 설정 `org.yaml`에 둔다. 에이전트마다 `avatar`, `[별채]` 게시는 최상위 `bot_avatar`다. 비우면 지금처럼 웹훅 기본 사진이다. 예전 이름(`former`)으로 불러도 지금 이름의 사진을 쓴다.
3. **주소 형식**: Discord가 주소에서 사진을 직접 내려받으므로 `https://` 주소만 받는다. 다른 값이면 org.yaml을 불러올 때 오류로 알린다.
4. **사진 파일**: 별직원 원화(`output/characters/원화/`, 2026-11-09)를 그대로 쓴다. 캐릭터를 가운데에 둔 정사각형 사진을 이 공개 저장소의 `assets/avatars/<별 이름>.png`에 두고 GitHub raw 주소를 쓴다. 원화를 고치면 `scripts/make_avatars.py`로 다시 만든다.

## 결과

- 직원 글마다 사진이 붙어 누가 말했는지 바로 보인다. 봇 토큰과 연결은 늘지 않는다.
- 웹훅 사진은 그 메시지에만 붙는다. 멤버 목록에는 여전히 별채 봇 하나만 보인다.
- 봇이 웹훅 없이 직접 보내는 글(`#zerosync-ops`, `#대표실` 알림 등)은 봇 계정의 이름과 사진으로 보인다. 이것은 Discord Developer Portal에서 바꾼다.
- raw 주소는 develop에 merge된 뒤에야 열린다. 사진을 바꾸면 Discord 캐시 때문에 늦게 반영될 수 있어, 바꿀 때는 파일 이름을 바꾸거나 주소 끝에 `?v=2`를 붙인다.
