# ADR-016 모든 Discord 글을 직원 이름으로

2026-11-19 Zero 결정.

## 배경

ADR-015로 웹훅 글에는 직원 이름과 사진이 붙는다. 그런데 봇 계정이 직접 보내는 글이 남아 있었다. `#대표실` 아침·주간 보고와 홀딩 알림, `#비서` 아침 보고·하루 정리, `#교육` 알림과 문제 버튼, 운영 채널 알림이다. 이 글은 Discord에 봇 계정 이름(예전 이름 ZeroSync)과 기본 사진으로 보였다. `#비서` 글은 본문 첫 줄에 `[폴라리스 · 비서실장]`을 적었지만, 게시자는 여전히 봇 계정이었다.

Zero는 모든 글이 별채 직원 이름으로, 역할에 맞게 나오기를 원했다.

## 결정

1. **경로**: 봇 계정이 직접 보내던 글도 그 채널의 웹훅으로 보낸다. 게시자 이름과 사진은 ADR-015와 같다.
2. **게시자**:

   | 채널 | 글 | 게시자 |
   |---|---|---|
   | `#대표실` | 아침·주간 보고, 채용 제안, 주기 작업 홀딩 알림 | 비서실장 (`secretary.agent`). 비서 설정이 없으면 `[별채]` |
   | `#비서` | 아침 보고, 하루 정리 | 비서실장 |
   | `#교육` | 학습 알림, 주간 보고, 문제·완료 버튼 | 교육팀장 (`education.agent`) |
   | 운영 채널 | 봇 오류, 사용량 한도, 시작 실패 | `[별채]` (직원 판단이 아닌 시스템 알림) |

   게시자가 이름과 사진으로 보이므로, 본문 첫 줄에 붙이던 `[이름 · 직책]`은 뺀다.
3. **웹훅 준비**: `#대표실`과 운영 채널 웹훅은 처음 보낼 때 찾거나 만들고 기억한다. 웹훅을 얻지 못하면(권한 없음, 텍스트 채널 아님) 그 글만 봇 계정으로 보낸다. 알림이 사라지지 않게 하기 위해서다.
4. **버튼**: 문제·완료 버튼도 웹훅 글에 붙인다. 봇이 만든 웹훅의 글이라 버튼을 누르면 봇이 받는다. 버튼 처리(`DynamicItem`)는 그대로다.
5. **운영 채널 이름**: `#zerosync-ops`를 `#별채-운영`으로 바꾼다. 봇은 채널을 ID(`OPS_CHANNEL_ID`)로 찾으므로 Discord에서 이름만 바꾸면 된다.

## 결과

- 일반 글에는 봇 계정 이름이 보이지 않는다.
- 슬래시 명령의 답(Zero에게만 보이는 글)은 Discord 구조상 웹훅으로 보낼 수 없어 봇 계정 이름으로 나간다. 봇 계정 이름과 사진은 Developer Portal에서 별채로 바꾼다.
- 웹훅 버튼은 실제 서버에서 아직 확인하지 않았다. 첫 아침 학습에서 문제·완료 버튼이 눌리는지 확인한다.
