# ADR-011 제품별 담당자와 기획팀장 보고

2026-11-06 Zero가 기획팀원 세 명의 채용과 배정을 결정했다. 가게씨는 Kappa, 제이데이는 Lambda, 오롯은 Mu가 맡는다. 세 사람은 프로젝트의 진행과 막힌 점을 추적해 Beta에게 보고한다. 기획·설계 승인과 제품 간 우선순위 결정은 Zero가 맡는다.

## 보고가 생기는 시점

- 작업이 완료되거나 중지되거나 사람의 도움이 필요한 상태가 되면 담당자에게 보고를 배정한다. 처음 담당자를 배정할 때 이미 막혀 있던 작업도 한 번 인계한다.
- 제품 채팅에서 담당자를 불러 일을 맡기면 그 요청과 응답 결과도 보고 대상이 된다.
- 담당자는 해당 사건 시점까지의 기록으로 한 일, 막힌 점, 다음 행동을 작성한다. 다른 직원이 구현하거나 검증한 일은 실제 수행자를 밝힌다.

## 전달과 복구

- 봇은 작업 상태 전이 또는 채팅 응답을 기록하는 트랜잭션에서 보고도 접수한다. 담당자는 제품 작업과 독립된 읽기 전용 호출로 JSON을 작성한다. 보고에는 담당자의 하루 호출 한도가 적용된다.
- 봇이 검증한 원본은 SQLite의 팀장 수신함에 저장한다. Beta가 해당 제품의 대화나 작업을 수행할 때 한 번에 최대 다섯 건을 읽는다. 읽지 않은 보고 중 오래된 건이 먼저이며, 성공한 호출에서만 읽음으로 표시한다.
- 작업 포스트 또는 담당자를 부른 채팅에 보고 사본을 멘션 없이 올린다. 포스트가 없는 정기 테스트는 수신함에만 전달한다.
- 보고 작성 실패는 한 시간 뒤 다시 시도한다. 재시작하면 미전달 건부터 이어 간다. Discord 사본 게시 실패는 로그에 남기며 Beta가 받은 원본은 보존한다.

## 오롯의 등록

봇의 프로젝트 키는 `orot`, 앱 저장소는 `FocusSense`, 볼트 폴더는 `FocusOps`다. 저장소의 iOS 테스트를 실행할 Xcode 프로젝트 파일이 준비될 때까지 `test: null`로 둔다. 테스트 단계가 포함된 일정은 실행하지 않으며, 수동 작업이 테스트 단계에 도달하면 막힘으로 기록한다.
