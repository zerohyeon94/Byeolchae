# ADR-017 세 엔진(Claude·Codex·Gemini)의 권한 통일

2026-11-22 Zero 결정.

ADR-012의 "Codex 구현 허용" 절 가운데 "기획·디자인·설계 문서 단계는 Claude만 맡는다"와 운영 규약 1.3의 같은 문장을 대체한다.

## 배경

운영 규약 1.3은 "권한은 엔진이 아니라 단계별 담당에 붙는다"고 정했다. 그런데 실제로는 엔진마다 권한이 달랐다.

| 항목 | Claude | Gemini(Antigravity `agy`) | Codex |
|---|---|---|---|
| 맡을 수 있는 단계 | 전부 | 전부 | 읽기 단계와 구현·수정만 (R4) |
| 문서 단계 쓰기 범위 | 자기 폴더만 | 자기 폴더만 | 맡지 못함 |
| 개념 노트 웹 검색 | 허용 | 웹 가져오기 허용 | 없음 |
| `.env` 변경 차단 | 도구 권한 | 도구 권한 | 없음 |

Codex만 다른 이유는 샌드박스가 폴더 단위라는 점이었다. `workspace-write`는 worktree 전체를 열어, 문서 단계를 `docs/기획/` 같은 폴더로 좁힐 수 없다. Zero는 엔진을 바꿔도 맡을 수 있는 일과 쓸 수 있는 범위가 같기를 원했다.

## 결정

1. **단계**: 세 엔진 모두 모든 단계를 맡는다. org.yaml 불러오기의 Codex 쓰기 단계 검사(R4의 엔진 조건), 파이프라인의 같은 검사, `cli.codex_models`의 단계 제한을 없앤다. R1(작성자와 리뷰어 분리)과 R6(팀장 확인)은 그대로다.
2. **쓰기 범위**: 단계별 쓰기 범위는 운영 규약 1.3 표 그대로다. 문서 단계 폴더는 `bot/agents/base.py`의 `DOC_STAGE_DIRS` 하나로 두고 Gemini 정책과 실행 뒤 검사가 함께 쓴다.
3. **Codex 실행**: 기획·디자인·설계·구현·수정은 `workspace-write`(worktree와 원래 저장소의 `.git`), 그 밖은 `read-only`. 웹 검색은 개념 노트만 `codex --search exec`로 켜고, 다른 단계는 `-c web_search="disabled"`로 끈다. codex-cli 0.161은 웹 검색이 기본으로 켜져 있기 때문이다. ChatGPT 앱·플러그인(`codex_apps` MCP)은 모든 단계에서 끈다(`--disable apps --disable plugins`). 웹 검색을 꺼도 앱의 검색 도구로 돌아가기 때문이며, Claude의 `--strict-mcp-config`와 같은 자리다.
4. **실행 뒤 검사 (엔진 공통)**: 쓰기 단계가 끝나면 봇이 실행 전 커밋과 HEAD의 차이(`git diff --name-only --no-renames`)를 본다. 문서 단계가 자기 폴더 밖을 바꿨거나, 어느 단계든 `.env`를 바꿨으면 형식 오류처럼 문제를 붙여 1회 다시 요청한다. 그래도 남으면 NEEDS_HUMAN으로 넘긴다(운영 규약 2.1). 커밋별이 아니라 실행 전후 차이를 보는 것은, 에이전트가 되돌린 변경까지 문제 삼지 않기 위해서다. Claude·Gemini는 도구 권한으로 미리 막으므로 이 검사에 걸리지 않는 것이 정상이다.

## 결과

- 엔진을 바꿔도 맡는 일과 쓰기 범위가 같다. 회사 설정에서 엔진만 바꾸면 된다.
- 완전히 같지 않은 점이 남는다. Codex는 경로별 읽기 차단이 없어 `.env`와 볼트 `회사/`를 읽는 것은 막지 못한다. 막는 것은 실행 뒤 발견되는 변경뿐이다. 실제 저장소의 `.env`는 Codex의 쓰기 범위(worktree와 `.git`) 밖이고 worktree에는 체크아웃되지 않으므로, 쓰기 위험은 커밋 검사로 충분하다고 본다.
- Codex가 문서 단계에서 폴더 밖 파일을 고치면 Claude·Gemini와 달리 실행 중에는 막히지 않고 재요청 한 번을 쓴다.
- 2026-11-22 실제 호출로 확인했다(codex-cli 0.161, 러너 인자 그대로). 개념 노트는 웹 검색으로 답했고, 의견 단계는 "웹 검색 불가"로 답했다. 끄기 전에는 의견 단계도 웹 검색을 썼고, 웹 검색만 끄면 `codex_apps`의 `search_service.web_run`으로 돌아갔다.
- 확인하지 않은 것: Antigravity의 웹 검색 도구 여부는 첫 개념 노트 실행에서 확인한다.
