# ADR-014 주기 작업 홀딩

2026-11-17 Zero 결정.

## 배경

봇은 정해진 시각에 주기 작업을 돌린다. 아침 보고, 주간 보고, 비서 저녁 하루 정리, 교육 아침 학습과 주간 보고, 제품별 정기 테스트다 (SPEC 6.6).

2026-11-17 Zero는 정기 테스트 이후 과정이 아직 불안정하다고 보고, jday·가게씨 정기 테스트와 교육 일정을 멈추기로 했다. 그런데 이것을 멈추는 방법이 설정을 지우는 것밖에 없었다.

- 정기 테스트를 멈추려면 `projects.yaml`의 `test`를 `null`로 바꿔야 했다. 그러면 기능 개발·수정 단계의 테스트 검증도 함께 빠진다.
- 교육 일정을 멈추려면 `education` 설정을 통째로 빼야 했다. 그러면 `#교육` 대화와 `/daily`도 함께 멈춘다.
- 어느 경우든 봇을 재시작해야 했다.

설정은 그대로 두고 주기 작업만 잠깐 멈추고 다시 켜는 방법이 필요하다. Zero는 웹 대시보드에서 버튼으로 하기를 원했다.

## 결정

1. **홀딩 단위**: 주기 작업 하나씩 홀딩할 수 있고, 전체 홀딩(`*`)도 둔다. 작업 키는 `schedule_runs`의 키와 같다 (`morning_report`, `education_daily`, `gagaessi:nightly-test` 등).
2. **저장**: 홀딩 중인 작업 키 목록을 봇 DB `bot_state`의 `schedule_holds`에 JSON으로 둔다. DB 구조는 바꾸지 않는다.
3. **홀딩 중 동작**: 예정 시각이 되면 실행한 것으로 기록만 하고 실행하지 않는다. 그래서 풀었을 때 홀딩 중에 지난 실행을 따라잡지 않고, 다음 예정 시각부터 돈다. 봇이 꺼져 있어 놓친 실행을 한 번 따라잡는 규칙(SPEC 6.6)은 그대로다.
4. **조작 위치**:
   - 웹 대시보드에 작업별 홀딩 버튼을 둔다. 웹은 지금처럼 DB를 읽기 전용으로만 연다. 버튼을 누르면 웹이 봇에 요청하고, DB에는 봇이 쓴다. "쓰는 주체는 봇 하나" 원칙을 지킨다.
   - Discord `/hold 작업 동작`도 둔다. 웹을 못 열 때 쓴다. 어느 채널에서든 Zero만 쓸 수 있다.
5. **로컬 제어 요청**:
   - 봇은 `127.0.0.1:8770`에서만 요청을 받는다 (`bot/control.py`). 경로는 `GET /schedules`(목록과 홀딩 상태)와 `POST /holds`(`{"job", "held"}`) 둘이다.
   - 요청에는 봇이 만든 토큰 파일(`~/.zerosync/control.token`, 권한 0600)의 값을 헤더 `X-Byeolchae-Token`으로 실어야 한다. 브라우저의 다른 웹페이지가 로컬 주소로 몰래 보내는 요청을 막기 위해서다.
   - 새 의존성은 없다. discord.py에 들어 있는 aiohttp를 쓴다.
   - 제어 서버를 열지 못하면 운영 채널에 알리고 봇은 계속 돈다. 이때는 `/hold`로 조작한다.
6. **알림**: 홀딩하거나 풀면 `#대표실`에 한 줄 남긴다 (무음). 아침 보고와 `/ping`에 홀딩 중인 작업을 표시한다.
7. **목록 하나**: 주기 작업 목록 계산(`scheduled_jobs`)은 `bot/scheduler.py` 한 곳에 둔다. 봇의 일정 실행기, `/hold`, 웹이 같은 목록을 쓴다.

## 결과

- 정기 테스트를 홀딩해도 기능 개발·수정 단계의 테스트 검증은 그대로 돈다. 교육 일정을 홀딩해도 `#교육` 대화와 `/daily`는 그대로 쓸 수 있다.
- 2026-11-17에 임시로 꺼 둔 설정(가게씨·jday `test`, `education`)은 되돌리고 홀딩으로 바꾼다.
- 미검증: 실제 봇에서 제어 서버가 discord.py와 같은 이벤트 루프에서 계속 응답하는지. 테스트는 실제 소켓으로 요청·응답만 확인했다.

## 검토한 대안

- **Discord 명령만**: 가장 작지만 Zero가 원한 웹 버튼이 없다.
- **웹이 DB에 직접 쓰기**: 빠르지만 웹의 읽기 전용 원칙과 "쓰는 주체는 봇 하나" 규칙을 바꿔야 한다. 봇이 같은 DB를 쓰는 중에 다른 프로세스가 쓰는 경로가 하나 더 생긴다.
- **풀 때 한 번 따라잡기**: 풀자마자 밀린 작업이 한꺼번에 돌 수 있어 택하지 않았다.
