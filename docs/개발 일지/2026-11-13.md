# 2026-11-13

## 한 것

- 볼트(`zerohyeon-labs`)의 `.git`을 iCloud 밖 `~/.zerosync/vault.git`으로 옮기는 스크립트 `scripts/migrate_vault_git.sh`를 추가했다. 봇이 도는 Mac에서 실행하며, 인자 없이 실행하면 점검만 한다. `--apply`는 봇을 멈추고 `.git`을 백업한 뒤 iCloud 찌꺼기(`index 2`, `.DS_Store`)를 치우고 `git init --separate-git-dir`로 옮긴 다음 봇을 다시 켠다. `--cleanup`은 원본과 내용이 같은 iCloud 충돌 사본과 NFC/NFD 중복 경로를 지우는 커밋을 만들고 push한다.
- 볼트 복제본과 로컬 bare 저장소로 시험했다. git 검사 통과, 정리 커밋 76개 파일 삭제(충돌 사본 24, 중복 경로 52), 새 clone 경고 없음, 커밋 안 된 변경 보존, 재실행 시 "이미 옮겨져 있다"로 끝나는 것을 확인했다.

## 막힌 것·발견한 것

- 볼트 폴더를 iCloud와 git이 함께 동기화해서 `.git/index 2` 같은 충돌 사본이 생기고 있었다. 봇 Mac과 다른 Mac이 같은 `.git`을 iCloud로 공유하는 구조라 git 기록이 손상될 위험이 있다.
- 볼트 저장소에 같은 노트가 NFC와 NFD 두 이름으로 52쌍 들어 있었다. 내용은 모두 같았다. macOS에서 clone하면 경로 충돌 경고가 난다.
- 첫 시험에서 `git status -sb | head -1`이 `pipefail`과 만나 SIGPIPE(141)로 스크립트가 중간에 끝났다. `sed -n 1p`로 바꿨다.
- 이 단계 뒤에도 md 파일은 iCloud에 남는다. iPad ZeroDesk 읽기와 `.zerodesk/필기` 쓰기는 그대로 동작한다.
