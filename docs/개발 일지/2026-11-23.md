  - 새 단계 `research`를 세 엔진 모두 개념 노트와 같은 웹 허용으로 돌린다(`WEB_STAGES`)
  - 슬래시 명령 `/research`는 Zero 결정으로 만들지 않았다
- 운영 규약 1.3·1.6-2·3.4, 문서 인덱스, AGENTS.md(다음 ADR 번호 019), ADR-012·ADR-017에 조사 보고를 반영했다.

## 막힌 것·발견한 것

- Zero가 `#대표실`과 Jday 채널에 쓴 글이 반영되지 않았다. 봇은 `#대표실`에 보고만 올리고 글은 읽지 않는다. Jday 대화 기록은 10-28 뒤로 없어, 봇이 듣지 않는 채널에 쓴 것으로 보인다. 봇이 받는 곳은 제품 채팅 채널, 제품 포럼, `#비서`, `#교육`이다.
- Gemini(`agy` 1.5.14) 헤드리스 실행에서는 URL을 직접 여는 도구를 쓸 수 없었다. 도구 목록에 `read_url_content`가 있어도 plan 모드, 기본 모드, 권한 설정 없음 모두 "웹 페이지 읽기 도구가 없다"고 답했다. 처음 실행에서는 `python urllib`로 페이지를 가져오려다 셸 거부에 막혔다. Gemini 조사는 `search_web` 검색 요약에 기댄다.
- Claude `WebFetch`는 유튜브 채널 페이지를 열어도 자바스크립트로 그리는 부분이 빠져 푸터만 읽혔다. 채널 RSS(`feeds/videos.xml?channel_id=`)는 채널 이름, 최근 영상 제목, 날짜까지 읽혀 조사 프롬프트에 안내했다. 구독자 수는 HTML 원문에는 있지만 `WebFetch` 결과에서는 빠진다.
- 기본 조직에서는 Codex 팀원이 교육팀 Iota뿐이라, 팀원 조사와 팀장 확인 테스트를 Iota와 Eta로 썼다.
