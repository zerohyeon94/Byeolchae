  - `bot/org.py` 기본 조직 12명: 아르크투루스(beta), 알비레오(gamma), 리겔(alpha), 미자르(delta), 알니탁(epsilon), 샤울라(zeta), 투반(eta), 베텔게우스(iota), 폴라리스(theta), 알데바란(kappa), 폴룩스(lambda), 시리우스(mu). 표시 이름은 한글이고 예전 이름은 `former`에 남겼다. 폴라리스 직책은 비서실장(`title: 실장`)이다
  - `Roles` 기본값(의견 담당 아르크투루스·리겔, 설계·구현 리겔, 리뷰 미자르, 문서 아르크투루스), 기본 파이프라인(`bot/pipeline.py`), 대화 기본 명단(`bot/workflow/state.py`), 교육·비서 기본 담당(`bot/config.py`의 `thuban`, `polaris`)
  - 저장소 예시: `examples/company/org.yaml`, 인격 파일 12개(파일 이름도 새 이름), 파이프라인 4개, `bot/projects.example.yaml`
  - 테스트와 프롬프트 스냅샷(파일 이름 포함)을 새 이름으로 옮겼다. 기본 조직의 예전 이름 연결 테스트를 더했다. ADR-005 기준 기록 이름(`Beta · Claude`, `Alpha · Codex`)은 그대로다
- 엔진, 팀, 관점은 바꾸지 않았다. 이름만 옮겼다
- ADR-012 따르는 변경, AGENTS.md 조직 설명을 고쳤다

## 막힌 것·발견한 것

- 이름을 한꺼번에 바꾸는 스크립트가 테스트의 Python `lambda` 키워드까지 `pollux`로 바꿨다. 예전 이름 `lambda`가 키워드와 같기 때문이다. 바로 되돌렸다
- 받침 있는 이름(리겔, 투반, 알니탁, 알데바란) 뒤 조사가 어색해진다. 봇 문구 `f"{이름}가 ..."`는 "투반가 개념 노트를 쓰지 못했다"처럼 나온다. 운영 회사 설정은 이미 별 이름이라 지금도 같은 문구가 나오고 있다. 이번 변경에서는 고치지 않았다
- 이 환경(UTC)에서는 일정 테스트 4개가 실패한다. `TZ=Asia/Seoul`로 돌리면 모두 통과한다. 이번 변경 전에도 같았다
