  - Codex도 기획·디자인·설계 단계를 맡는다. org.yaml·파이프라인의 Codex 쓰기 단계 검사와 `cli.codex_models` 단계 제한을 없앴다
  - Codex 개념 노트는 `codex --search exec`로 웹 검색을 켜고, 다른 단계는 웹 검색과 ChatGPT 앱·플러그인을 끈다
  - 문서 단계 폴더를 `bot/agents/base.py`의 `DOC_STAGE_DIRS`로 모았다
  - 쓰기 단계가 끝나면 실행 전후 차이(`GitOps.changed_files`)를 보고, 자기 폴더 밖이나 `.env` 변경이 있으면 다시 요청한다(`scope_violations`)
- 운영 규약 1.3, ADR-012(문서 단계 제한 줄 대체 표시), 문서 인덱스, AGENTS.md 다음 ADR 번호를 고쳤다.
- 비서 토큰 집계에 Gemini를 넣었다. 봇 몫은 실행 로그의 `result` 이벤트, Zero 몫은 Antigravity CLI·데스크톱 앱 대화 DB의 사용량 숫자다. 봇 실행 대화는 Zero 몫에서 뺀다 (ADR-010).

## 막힌 것·발견한 것

- 처음 시작하려 할 때 다른 에이전트가 같은 파일(Gemini 연동)을 고치는 중이었다. 브랜치를 되돌리고 그 작업이 끝날 때까지 기다렸다.
- 처음에는 새 커밋마다 바뀐 파일을 검사했다. 그러면 에이전트가 잘못 바꾼 파일을 되돌려도 첫 커밋이 계속 걸려 재요청이 의미가 없었다. 실행 전 커밋과 HEAD의 차이를 보도록 바꿨다.
- Codex 웹 검색을 실제로 호출해 확인했다. codex-cli 0.161은 `--search` 없이도 웹 검색이 켜져 있어 의견 단계도 검색했다. `web_search="disabled"`만 주면 ChatGPT 앱(`codex_apps` MCP)의 `search_service.web_run`으로 돌아갔다. `--disable apps --disable plugins`까지 주니 "웹 검색 불가"로 답했고, 개념 노트는 여전히 검색했다. 앱 MCP가 OAuth 인증 오류를 내던 줄도 사라졌다.
- Antigravity(`agy` 1.5.14)를 실제로 호출해 보니 Gemini 러너는 실행되지 않았다. `-p`가 바로 뒤 인자(`--output-format`)를 프롬프트로 받고 stdin은 읽지 않기 때문이다. stdin에 `{"event":"user","message":{...}}`를 넘기는 `--input-format stream-json --output-format stream-json`으로 바꾸고, 마지막 `result` 이벤트를 읽게 했다. 의견(구조화 출력)과 개념 노트가 실제로 돌았다.
- Antigravity 웹 검색 도구 `search_web`은 권한 규칙으로 막히지 않았다(`read_url(*)` 차단, `search_web(*)`, plan 모드 없이 모두 검색함). 끄는 설정 키도 없다. Zero 결정으로 차이를 ADR-017에 남겼다.
- Gemini 쓰기 권한을 실제로 확인했다. 처음 규칙으로는 쓰기 단계의 git 명령이 모두 실패했다. 상대 경로 `.env`와 glob `**/.env` 때문에 터미널 샌드박스 설정 오류가 났고, `.git` 쓰기도 열려 있지 않았다. `.env`·`회사/` 거부를 절대 경로로 바꾸고 `.git` 쓰기를 열었다. 그 뒤 worktree에서 커밋 성공, push 거부, `.env` 읽기·쓰기 거부를 확인했다.
- Gemini 문서 단계의 폴더 제한은 듣지 않는다. 맞는 규칙이 없는 쓰기는 기본으로 허용되고, `toolPermission: strict`는 허용 규칙까지 무시한다. 폴더 제한은 Codex처럼 실행 뒤 검사가 맡는다(ADR-017).
- Codex는 경로별 읽기 차단이 없어 `.env`·볼트 `회사/` 읽기는 막지 못한다. ADR-017 결과에 적었다.
- Antigravity 대화 DB(SQLite)의 `gen_metadata`는 protobuf라 필드 번호를 실제 숫자와 맞춰 찾았다. 입력 1.4.2, 출력 1.4.3, 캐시 읽기 1.4.5이고, 시각은 모델 응답 단계(`step_type` 15)와 순서대로 짝이 맞는다. 공식 형식이 아니라 agy가 바뀌면 0이 될 수 있다. Gemini 구독 한도 정보는 찾지 못했다.
