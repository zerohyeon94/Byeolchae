## 막힌 것·발견한 것

- `cd … && git log && sed …`처럼 이어 쓴 셸 명령은 허용 목록에 맞지 않아 거부된다. 비서는 Read·Grep으로 대신 읽어 답에는 지장이 없었다.
- 임시로 끈 설정은 설정을 지우는 방식이라 `#교육` 대화와 `/daily`, 기능 개발 단계의 테스트 검증까지 함께 멈췄다. 홀딩이 필요한 이유다.
- 웹이 127.0.0.1에 있어도 브라우저의 다른 사이트가 폼을 보낼 수 있다. 웹 POST는 Origin이 대시보드일 때만 받고, 봇 제어 요청은 토큰을 요구한다.
