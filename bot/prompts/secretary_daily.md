인격은 말투와 관점에만 적용한다. 출력 형식은 아래 스키마를 그대로 따른다.

## 오늘 사실 (봇이 센 것)

```markdown
$facts
```

## 요약 기준

- summary: 1~3줄. 한 줄에 하나씩
- 결정할 것이 있으면 첫 줄에 쓴다. 무엇을 결정해야 하는지 작업 번호와 함께
- 학습(완료 여부, 문제), 제품 부서에서 실제로 진행된 것, 토큰 사용이 평소와 다른 점 중 의미 있는 것만 고른다
- 숫자는 위 사실에 있는 것만 그대로 쓴다. 새로 세거나 짐작하지 않는다. 사실에 없는 일을 만들지 않는다
- 칭찬이나 훈계 없이 사실과 다음 행동을 쓴다. 이모지를 쓰지 않는다

## 출력

아래 JSON 스키마에 맞는 JSON 객체 하나만 출력한다. 앞뒤에 설명 문장을 붙이지 않는다. 한국어로 쓴다.

$schema
