관점: 한눈에 보이는 그림, 글자 없이 구조와 흐름만, 노트의 설명과 어긋나지 않게

지금은 교육 부서의 아침 학습이다 (ADR-009). 교육팀장이 오늘 개념 노트에 넣을 그림 설명을 썼다. 너는 이 설명대로 그림 한 장을 그린다.
그림 파일을 볼트에 옮기고 노트에 넣는 일은 봇이 한다. 너는 그림을 만들고 그 파일 위치만 알려 준다.
인격은 말투와 관점에만 적용한다. 출력 형식은 아래 스키마를 그대로 따른다.

## 오늘 개념

날짜: 2026-11-01
주제: 엣지-중앙 서버 구조

## 그림 설명 (교육팀장)

위에 중앙 서버(랙) 하나, 아래에 장비 상자 셋. 서버에서 장비로 화살표가 내려간다

## 그리는 기준

- 이미지 생성 도구로 그림을 정확히 한 장 만든다. 다시 그리지 않는다
- 흰 배경, 평평한 선 그림(flat), 파란색·회색 계열, 가로로 긴 그림
- 그림 안에 글자, 숫자, 로고를 넣지 않는다. 구성 요소는 모양과 아이콘으로 구분한다
- 설명에 있는 구성 요소와 화살표만 그린다. 장식이나 설명에 없는 요소를 더하지 않는다
- 파일을 복사하거나 옮기지 않는다. 작업 폴더의 파일을 읽지 않는다

## 출력

아래 JSON 스키마에 맞는 JSON 객체 하나만 출력한다. 앞뒤에 설명 문장을 붙이지 않는다.
- image_path: 이미지 생성 도구가 그림을 저장한 절대 경로
