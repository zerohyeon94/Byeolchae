# 별채 웹사이트

별채(Byeolchae)는 대표 라군(Lagoon)과 별 이름을 가진 직원들이 함께 앱을 만들고, 그 과정을 영상으로 나누는 회사다. 회사 홈에서 별직원들을 만나고, 업무 화면에서는 지금 누가 어떤 일을 진행하는지 확인할 수 있다.

> 앱 하나, 이야기 한 편이 누군가의 밤에 작은 빛이 되기를.

## 화면 안내

| 화면 | 경로 | 볼 수 있는 내용 |
| --- | --- | --- |
| 회사 홈 | `/` | 회사 소개, 오늘의 작업, 라군의 결정을 기다리는 일, 밤 근무표 |
| 팀원 소개 | `/org/stars` | 별직원의 얼굴과 역할, 성격, 일할 때 던지는 질문 |
| 조직도 | `/org` | 대표·부문·팀의 관계와 각 팀의 구성원 |
| 업무 요약 | `/summary` | 진행 중인 작업, 대표가 할 일, 예산과 제품별 현황 |
| 교육 | `/education` | 월별 학습 목표, 학습 대기열과 최근 학습 기록 |
| 기능 | `/features` | 봇 기능과 일정, 업무 구성도와 흐름도 |

## 로컬에서 열기

프로젝트의 Python 환경과 설정을 준비한 뒤, 저장소 루트에서 다음 명령을 실행한다.

```sh
.venv/bin/python -m bot.dashboard
```

브라우저에서 [별채 홈](http://127.0.0.1:8765/)을 연다. 대시보드는 로컬에서 실행되며 봇의 작업 기록과 설정을 읽어 화면에 표시한다. 기본 포트를 사용 중이면 실행 명령 뒤에 `--port 8766`을 붙이고 해당 포트로 접속한다.

## 수정할 곳

- 회사 소개와 이름의 기준은 [회사 헌장](../docs/회사/01-헌장.md)에 있다. 별채와 라군은 웹사이트의 회사명과 대표 활동명이며, 봇과 저장소 이름은 ZeroSync다.
- 화면에 표시하는 한글·영문 이름은 [identity.py](../bot/dashboard/identity.py), 회사 홈의 문구와 구성은 [company.py](../bot/dashboard/company.py)에서 수정한다.
- 전체 웹 구현은 [bot/dashboard/](../bot/dashboard/)에 있고, 화면별 동작은 [대시보드 테스트](../tests/test_dashboard.py)에서 확인할 수 있다.
